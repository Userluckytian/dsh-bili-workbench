dsh-bili-workbench B站工作台

一个 DSH（DeepSeek Harness） 插件：把「刷 B站 / 素材库 / AI 出片 / 审核发布 / 自动互动」放进同一个工作台。

刷B站采素材 → 记忆沉淀 → AI 出片 → 审核发布 → 自动互动

GitHub 仓库 完整文档
dsh plugin --profile web add github:Userluckytian/dsh-bili-workbench

功能一览

不是又一个「B站信息流面板」，而是一条从看到做再到发的完整流水线。

📚 素材库 · 六栏中枢

视频元数据、逐字稿（带时间戳）、关键帧、封面、AI 点评、可引用金句，外加热评 / 弹幕 / 热梗。按 BV 幂等，7 天内不重复抓。

视频索引音色试听片段预览表情包BGM贴纸

✍️ 创作 · 出片

一句话出方案 → 改一版（v1/v2…）→ 真实帧 + Edge-TTS 配音 + Remotion 渲染 1080p 成片与封面。

转场动效音效轨BGM 自动选曲动画形象真视频拼接

🧠 记忆系统

刷到的视频沉淀为素材记忆，日报与判定结论长期留存，出片引擎从记忆库里取真实帧和金句，越用越懂你的频道。

三层记忆自动复盘经历召回注入防护
✅

✅ 审核 · 发布

待审列表、通过 / 打回、预览成片、投稿 dry-run。真投稿默认关；打开后仍需二次确认，删成片也要确认。

三重闸门AI 声明预演投稿

💬 自动互动

每条采到的视频自动留一条评论并 @ 你；有人回复就自动回。12 秒发送间隔 + 每日上限，主人身份与只读指令，默认关。

自动评论带图评论主人 @ 任务礼貌拒绝

环境要求 · 会安装什么（依赖明细）

装之前先知道自己会装什么、各占多少空间。下面是实测占用参考。

组件是什么 / 干什么用怎么装大概占用必装?
dsh ≥0.2.1插件宿主（DeepSeek Harness），工作台跑在它的 web 界面里见 dsh 官方文档~50 MB必装
Node.js ≥22插件与出片引擎的运行时nodejs.org 安装包~110 MB必装
bili CLI（bili-agent）B站操作命令行：登录/搜索/评论/投稿都靠它uv tool install bili-agent 或 pip install bili-agent（需 Python 3.10+，~150 MB）~30 MB（不含 Python）必装
ffmpeg（full build）音视频处理：混音/烧字幕/封面/裁片段，必须含 libassgyan.dev 的 full 版，解压后把 bin 加 PATH~400 MB必装
yt-dlp从B站下载视频片段（名场面裁剪用）uv tool install yt-dlp~50 MB必装
edge-tts微软免费配音（4 种中文音色，出片旁白默认用它）随插件自动安装（bili-op 依赖）~10 MB必装（自动）
Remotion + React浏览器渲染出片的引擎dsh plugin add 时随插件自动安装（pnpm）~500 MB（node_modules 内）必装（自动）
GPT-SoVITS【可选】声音克隆：给视频角色配自定义音色（10 秒参考音即可克隆，CPU 可跑）git clone 官方仓库 + venv + v1 模型四件套，详见仓库 docs/指南-声音克隆.md~5 GB（含 torch CPU 与模型）可选
rembg【可选】本地抠图：把角色图片抠成透明 PNG 当视频形象uv tool install rembg，首次运行自动下载 bria-rmbg 模型~1.2 GB（模型 1 GB）可选

合计：必装全家桶约 1.2 GB；加声音克隆（GPT-SoVITS）约 6 GB。

安装三步

  1. 安装插件：
    dsh plugin --profile web add github:Userluckytian/dsh-bili-workbench
    装完重启 dsh，刷新浏览器，会话顶部出现「B站工作台」页签。
  2. 装外部命令：uv tool install bili-agent 并 bili auth login 扫码；winget install Gyan.FFmpeg；可跑 node scripts/doctor.mjs 自检。
  3. 准备素材包：素材不打进安装包，默认放素材库兄弟目录 <store>/../assets-src/（voices / clips / memes / bgm / stickers），可用环境变量 BILI_ASSETS 指向你的素材目录（优先级最高，改后重启生效）。目录不存在时素材页会提示，可在「我的 → 自检」查看状态。

素材目录说明

素材库目录 assets-src 默认在 <store>/../assets-src（完整素材包约 534 MB），可用环境变量 BILI_ASSETS 指向任意目录。首次使用可从 GitHub Release 附件下载素材包解压，或按下面的「素材从哪来」清单自行收集——每类素材只要放对目录 + 建好 index.json 就能被识别。
